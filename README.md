# Lattice design
This is an inofficial repo for documenting my own lattice design process.  

## Folders
### Candidates
Lattice candidates. These files follow a shortened version of the naming convention for ease of use. Each lattice candidate found in candidates/vNN_MM_OO_PP is generated in the file candidates/vNN_MM_OO_PP/lattice.ipynb. 
Lattices without a finilaized date are still work in progress and subject to change. 

### utils
Small collection of python utils used to handle at lattices, plotting etc. 

### test
Various notebooks exists for quickly testing code and ideas. These are not meant as documentation or official unit tests, rather as a tool for debugging.
